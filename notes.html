SQL JOINs Reference

SQL JOINs Reference

JOINs combine rows from two or more tables based on a related column between them.

INNER JOIN

SELECT c.customer_name, o.order_date, o.total_amount
FROM customers c
INNER JOIN orders o ON c.customer_id = o.customer_id
WHERE o.order_date >= '2024-01-01';

Returns only matching rows from both tables. If a customer has no orders, they won't appear.

LEFT JOIN

SELECT c.customer_name, COUNT(o.order_id) as order_count
FROM customers c
LEFT JOIN orders o ON c.customer_id = o.customer_id
GROUP BY c.customer_name;

Returns ALL customers even those with no orders (their count will be 0 or NULL).

FULL OUTER JOIN

Returns all rows from both tables. Unmatched rows show NULL for missing side.

When to Use Which JOIN

  • INNER JOIN — Only need matched data (e.g., orders with known customers)
  • LEFT JOIN — Keep all records from main table (e.g., all customers, even inactive)
  • RIGHT JOIN — Rarely used; prefer LEFT JOIN by swapping table order
  • FULL OUTER JOIN — Need everything from both tables (e.g., reconciliation)

Business Example

To find customers who have NEVER placed an order (perfect for churn analysis):

SELECT c.customer_name
FROM customers c
LEFT JOIN orders o ON c.customer_id = o.customer_id
WHERE o.order_id IS NULL;
